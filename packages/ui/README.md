# @burupromo/ui

Design system BuruPromo — "Label Harga & Struk Belanja" (ARCHITECTURE.md §9).
Token hidup di `src/tokens.ts` (+ `tokens.css` / `tokens.js` mirror untuk Tailwind).
Komponen dasar: `PromoCard`, `SearchBar`, `VoucherCode`, `Countdown`, `Badge`.
Larangan: gradien ungu-biru, glassmorphism, blob, emoji sebagai ikon, hero generik.
